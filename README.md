# yourstrategy-site

The root landing page for **Your Strategy**, served at
[yourstrategy.co](https://yourstrategy.co) via GitHub Pages.

A small static site for the consultancy: contract technical product & program
management, custom app development, and links out to each app.

- `index.html`: the page
- `sole-account/index.html`: Sole Account coming-soon page, at `/sole-account/`
- `sole-account/privacy-policy/index.html`: Sole Account privacy policy, at `/sole-account/privacy-policy/`
- `styles.css`: stylesheet (shared by every page)
- `assets/`: app icons for the cards
- `CNAME`: apex custom domain for GitHub Pages
- `.nojekyll`: serve files as-is (no Jekyll build)

Apps linked:
- Reminder Wrangler → https://reminderwrangler.yourstrategy.co
- White Hot → https://whitehot.yourstrategy.co
- Sole Account → https://yourstrategy.co/sole-account/ (coming soon)

Plain static HTML/CSS, no build step. Edit and push to `main`; GitHub Pages
redeploys.
